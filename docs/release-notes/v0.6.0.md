## 中文

### 新增
- 新增统一的托盘快捷面板，可快速浏览最近 10 条剪贴板记录。
- 支持方向键选择、空格预览，以及双击或回车复制并粘贴内容。
- 可在设置中选择点击托盘图标时打开快捷面板或主窗口。

### 优化
- 快捷面板与主窗口使用独立窗口，切换时更稳定，并保留原应用的粘贴焦点。
- macOS 与 Windows 采用一致的托盘面板布局和交互。
- 设置页下拉选择器统一为无障碍组件，键盘和鼠标反馈更加一致。
- 优化剪贴板记录的来源、标题和类型信息，减少重复元数据。

### 修复
- 修复从托盘切换到主窗口时可能出现的尺寸闪动和定位异常。
- 修复托盘面板选择态、首条记录可见性和重复点击关闭行为。

## English

### Added
- Added a unified tray quick panel for browsing the 10 most recent clipboard items.
- Added arrow-key navigation, Space preview, and double-click or Enter to copy and paste an item.
- Added a setting to open either the quick panel or the main window from the tray icon.

### Improved
- The quick panel and main window now use separate windows for stable transitions while preserving the original paste target.
- macOS and Windows now share the same tray panel layout and interactions.
- Settings selects now use a shared accessible component with consistent keyboard and pointer feedback.
- Improved clipboard source, title, and type metadata while reducing duplicate details.

### Fixed
- Fixed size flicker and positioning issues when switching from the tray panel to the main window.
- Fixed tray selection styling, first-item visibility, and click-again-to-close behavior.
