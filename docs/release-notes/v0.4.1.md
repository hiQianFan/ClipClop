## 中文

### 优化
- 主面板在不同显示器与缩放比例下保持更稳定的尺寸与位置。
- macOS 分页反馈更轻、更连贯。

### 修复
- 修复多显示器下呼出主面板不稳定，以及连续使用全局快捷键时无法立即显示或隐藏的问题。
- 修复设置中打开发布页面失败时缺少提示的问题。
