## 中文

### 新增
- 版本历史统一从 ClipClop 官网读取，减少对 GitHub API 的依赖，并支持本地逐步加载更多版本。
- 清空历史和删除记录的确认操作改为可键盘操作的弹窗，默认聚焦危险操作按钮。

### 改进
- 优化 macOS 面板在外部点击时的关闭行为。
- 回滚 Windows 非激活面板实验，保持正式窗口行为稳定。

## English

### Added
- Version history now uses the ClipClop website feed, reducing direct GitHub API access and supporting local incremental loading.
- Clear-history and delete confirmations now use keyboard-operable dialogs with the destructive action focused by default.

### Improved
- Improved macOS panel dismissal when clicking outside the panel.
- Reverted the Windows non-activating panel experiment to keep the production window behavior stable.
