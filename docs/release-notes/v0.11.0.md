## 中文

### 新增
- 新增收藏：在历史列表中可用星标保存常用内容，并通过“全部 / 收藏”切换查看。
- 收藏内容会跳过清理和清空历史，取消收藏后恢复普通历史记录行为。

### 改进
- 历史列表固定展示 10 条可用行，避免收藏入口和文件组展开挤压列表。
- 优化翻页与预览加载的并发关系，图片或文件预览处理中不再阻塞历史查询。
- 文件 preview 只在需要时显示路径，不再为图片等内容保留空路径区域。

## English

### Added
- Added Favorites: star items in the history list and switch between All and Favorites.
- Favorite items are preserved during retention cleanup and clear-history actions until they are unfavorited.

### Improved
- The history list keeps 10 usable rows without inline file expansion reducing row space.
- Paging and preview loading are decoupled so image or file preview work no longer blocks history queries.
- File paths appear only for file previews, and image previews no longer reserve an empty path area.
