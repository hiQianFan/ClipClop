## 中文

### 优化
- 文件、文件夹和照片现在使用更清晰一致的信息栏，来源应用、复制时间、类型和大小更容易浏览。
- 无法内嵌预览的文件会直接显示完整路径；照片预览不再重复显示临时文件名和路径。
- macOS 文件访问设置现在明确指向完全磁盘访问权限，并可在访问受限时直接打开系统设置。
- 调整界面字号、行高和跨平台字体回退，提升信息密度下的可读性。

### 修复
- 修复从 macOS 照片复制图片时可能反复触发读取权限提示的问题。
- 修复文件夹被误识别为文件扩展名，以及 macOS 应用包无法通过 Space 使用 Quick Look 预览的问题。
- 修复 Windows 文件夹可能被误判为 macOS 文件访问权限问题。

## English

### Improved
- Files, folders, and photos now share a clearer metadata bar with easier-to-scan source, timestamps, type, and size.
- Files without an inline preview show their full path, while photo previews no longer repeat temporary filenames and paths.
- macOS file access now points clearly to Full Disk Access and opens System Settings directly when access is restricted.
- Increased interface type sizes, line heights, and cross-platform font fallbacks for better readability at high density.

### Fixed
- Fixed repeated file-access prompts when copying images from macOS Photos.
- Fixed folders being mistaken for filename extensions and macOS app bundles failing to open in Quick Look with Space.
- Fixed Windows folders being mistaken for macOS file-access permission failures.
