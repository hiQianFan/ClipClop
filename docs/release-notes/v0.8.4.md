## 中文

### 新增
- Windows 快速入门新增“功能准备”，可在体验前检测 QuickLook，并根据安装、兼容性和权限状态提供对应操作。

### 优化
- Windows 快速入门调整为“工作方式 → 功能准备 → 上手”，避免用户在未安装 QuickLook 时进入无法完成的 Space 预览练习。
- 只有 QuickLook 可用时，上手体验才会展示并启用 Space 预览；跳过安装不影响剪贴板历史、复制和粘贴功能。
- 从 QuickLook 安装页面返回 ClipClop 后会自动重新检测可用状态。
- macOS 快速入门流程保持不变，用户仍会先体验核心操作，再按需配置系统权限。

## English

### Added
- Windows Quick Start now includes a Get Ready step that checks QuickLook before practice and offers the appropriate action for installation, compatibility, and permission states.

### Improved
- Reordered Windows Quick Start to “How it works → Get ready → Try it,” preventing an unavailable Space preview exercise when QuickLook is not installed.
- Space preview is shown and enabled during practice only when QuickLook is ready; skipping installation does not affect clipboard history, copying, or pasting.
- ClipClop automatically checks QuickLook again after the user returns from its installation page.
- The macOS Quick Start flow is unchanged, so users still experience the core workflow before choosing system permissions.
