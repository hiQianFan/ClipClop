## 中文

### 改进
- 新增独立的 macOS 权限设置页，并在快速入门中展示自动粘贴权限状态。
- 从系统设置返回时重新检测辅助功能权限，状态变化更加及时。
- 优化未签名构建的权限恢复引导，帮助用户定位并重新授权当前 App。
- 统一设置页上下文工具栏与权限状态按钮的视觉样式。

### 修复
- 自动粘贴失败时明确提示辅助功能权限问题，并安全退化为复制内容。

## English

### Improved
- Added a dedicated macOS permissions page and automatic-paste status to onboarding.
- Recheck Accessibility permission when returning from System Settings for fresher status feedback.
- Improved permission recovery guidance for unsigned builds, including locating the current app for reauthorization.
- Unified contextual toolbars and permission-status button styling across Settings.

### Fixed
- Surface Accessibility failures during automatic paste while safely falling back to copying the content.
