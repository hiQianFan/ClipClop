## 中文

### 优化
- 快速入门现在先让你体验核心操作，再清晰说明自动粘贴与文件预览所需的系统权限。
- 文件预览权限统一交由系统管理，设置与引导流程更加直接。
- 文件无法内建预览时，会根据文件访问状态提供准确的权限或系统预览指引。

### 修复
- 修复文件预览开关与系统权限重复控制，导致预览状态和操作提示不一致的问题。

## English

### Improved
- Quick Start now demonstrates the core workflow before clearly explaining the system permissions used by automatic paste and file previews.
- File preview access is now managed directly by the operating system for a simpler Settings and onboarding flow.
- When an inline file preview is unavailable, ClipClop now gives an accurate access or system-preview hint.

### Fixed
- Fixed conflicting app and system permission controls that could make file preview states and guidance inconsistent.
