## 中文

### 新增
- 重构 macOS 权限引导：直接将 ClipClop 拖入无障碍或完全磁盘访问列表，授权过程更明确。
- 权限页与快速入门共享状态刷新、授权和重启流程，重启后自动返回原位置。

### 改进
- macOS 正式构建使用稳定的 `ClipClop Release` 自签身份，减少版本更新后重复授权的问题。
- 权限操作统一使用设置页按钮样式，并突出需要完成的“重启应用”操作。
- 手动检查更新时同步刷新版本历史，发布列表不再停留在旧版本。

## English

### Added
- Reworked macOS permission guidance so users can drag ClipClop directly into the Accessibility or Full Disk Access list.
- Settings and onboarding now share permission refresh, authorization, restart, and return behavior.

### Improved
- Production macOS builds use the stable `ClipClop Release` self-signed identity to reduce repeated authorization after updates.
- Permission actions follow the Settings button style and emphasize the required app restart.
- Manual update checks now refresh release history instead of leaving the list on an older version.
