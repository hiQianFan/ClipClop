> 安装提示 / Installation note
>
> 当前安装包尚未使用 Apple Developer ID 或 Windows Authenticode 签名。macOS 可能需要在“隐私与安全性”中批准，Windows 可能显示“未知发布者”或 SmartScreen 警告。更新文件的签名会校验完整性，但不提供操作系统级别的发布者身份。
>
> These installers are not currently signed with Apple Developer ID or Windows Authenticode. macOS may require approval in Privacy & Security, and Windows may show an Unknown Publisher or SmartScreen warning. Updater signatures verify update integrity but do not provide operating-system publisher identity.
