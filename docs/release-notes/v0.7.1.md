## 中文

### 优化
- Windows 托盘左键现在直接打开主面板，右键打开快捷面板。

### 修复
- 修复 macOS 混合缩放多显示器下快捷面板位置、尺寸不正确及显示跳动的问题。
- 修复 macOS 主面板未在光标所在屏幕安全区域内居中的问题。
- 修复切换主题后主面板与快捷面板颜色不同步的问题。

## English

### Improved
- On Windows, left-clicking the tray icon now opens the main panel, while right-clicking opens the quick panel.

### Fixed
- Fixed incorrect quick-panel placement, sizing, and visible jumps across mixed-scale macOS displays.
- Fixed the macOS main panel not centering within the cursor display's visible area.
- Fixed theme changes not staying synchronized between the main and quick panels.
