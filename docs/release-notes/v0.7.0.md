## 中文

### 新增
- 历史记录支持按内容类型、来源应用和时间范围筛选。
- 筛选面板显示各类型数量与可用来源，并支持组合搜索条件。
- 新增“保留上次搜索条件”设置，可在重新呼出 ClipClop 时恢复搜索词和筛选项。

### 优化
- 空历史和无匹配结果提供更清晰的状态说明与清除条件入口。
- 旧版代码类型记录统一迁移为文本，简化内容分类。

### 修复
- 修复 Windows 托盘快捷面板无法从托盘图标附近正确展开的问题。
- 快捷面板现在根据目标显示器的 DPI、完整边界和工作区统一计算尺寸与位置，改善多显示器和不同任务栏位置下的表现。

## English

### Added
- Added history filters for content type, source application, and time range.
- Added filter counts, available sources, and combined search conditions.
- Added a setting to preserve search text and filters when reopening ClipClop.

### Improved
- Empty history and no-match states now provide clearer guidance and a direct way to clear search conditions.
- Legacy code records are migrated to text for a simpler content model.

### Fixed
- Fixed the Windows tray quick panel opening away from the tray icon.
- The quick panel now derives its size and position from the target monitor's DPI, full bounds, and work area for better multi-monitor and taskbar placement.
