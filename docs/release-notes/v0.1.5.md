## 中文

### 修复
- Windows 通过全局快捷键呼出主面板后会立即获得键盘焦点，可直接用方向键选择并回车粘贴。

### 优化
- Windows 安装器改为每用户安装，无需管理员权限，并支持按系统语言显示。

## English

### Fixed
- On Windows, the panel now receives keyboard focus immediately after opening with the global shortcut.

### Improved
- The Windows installer now installs per user without administrator permission and follows the system language.
