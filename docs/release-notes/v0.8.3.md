## 中文

### 新增
- Windows 系统预览现由 QuickLook 提供，支持通过 Space 预览文本、图片、链接、颜色和文件。
- 设置页新增 QuickLook 安装状态、版本、兼容性和权限提示，并提供桌面版安装入口。

### 优化
- Space 预览不再依赖列表焦点，在 ClipClop 浏览状态下可直接打开当前内容。
- 优化 QuickLook 与 ClipClop 的窗口层级和关闭动画，预览不会再被 ClipClop 遮挡或在关闭时突然下沉。
- 设置页标题栏现在可以拖动窗口。

### 调整
- Windows 系统预览不再依赖 Microsoft PowerToys Peek。

## English

### Added
- Windows system previews are now powered by QuickLook, with Space previews for text, images, links, colors, and files.
- Settings now reports QuickLook installation, version, compatibility, and permission states, with a desktop installer entry point.

### Improved
- Space preview no longer depends on list focus and can open the current item anywhere in ClipClop's browse mode.
- Coordinated QuickLook and ClipClop window ordering and close transitions so previews are not obscured or sent behind ClipClop while closing.
- The Settings title bar can now be used to drag the window.

### Changed
- Windows system previews no longer depend on Microsoft PowerToys Peek.
