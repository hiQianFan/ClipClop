# Release notes

Each published version has one user-facing bilingual note: `vX.Y.Z.md`.

- Keep Chinese and English sections in the same order: Added, Improved, Fixed.
- Describe visible behavior and user impact; omit implementation detail, PR numbers, and internal refactors.
- Start from `TEMPLATE.md`.
- The workflow appends `_installation-note.md` to every GitHub Release. Update or remove that fragment when signing status changes.
