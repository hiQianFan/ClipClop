## 中文

### 新增

- 快捷键设置支持点击当前按键帽打开录制弹窗。
- 录制时实时展示按下的按键，支持保存、取消和恢复默认快捷键。

### 优化

- 编辑快捷键时暂时卸载应用全局快捷键，避免抢占录制输入。
- 系统或其他应用占用的组合键由原生注册结果判断，并保留原快捷键作为失败回退。

## English

### Added

- Click the current keycaps in Settings to open the shortcut recorder.
- Live key display with save, cancel, and restore-default actions.

### Improved

- The active global shortcut is temporarily unregistered while recording so it cannot consume the input.
- Native registration determines shortcut availability, with the previous shortcut preserved on failure.
