## 中文

### 新增
- 快捷面板支持分页浏览，可通过拖动、触控板横向滚动和键盘连续翻页。
- Windows 文件预览支持通过 PowerToys Peek 打开。
- 新增始终指向最新版安装包的稳定下载地址。

### 优化
- 统一按钮、快捷键提示、分页器和设置保存状态的交互反馈。
- 切换主面板视图和设置页面时更可靠地保留浏览状态。
- 品牌图标全部改为本地资源，保持离线可用。

### 修复
- 修复分页器悬停光标闪烁和部分区域错误显示文本选择光标的问题。
- 修复设置页面样式和视图切换后的状态恢复问题。
- 移除设置保存成功后的触觉反馈，同时保留分页转轮的步进反馈。

## English

### Added
- Added paged browsing to the quick panel with drag, horizontal trackpad scrolling, and keyboard navigation.
- Added PowerToys Peek support for file previews on Windows.
- Added stable download URLs that always point to the latest installers.

### Improved
- Unified interaction feedback across buttons, shortcut hints, the pager, and settings save states.
- Improved browse-state preservation when switching main-panel views and settings pages.
- Moved brand icons to local assets for reliable offline use.

### Fixed
- Fixed pager cursor flicker and text-selection cursors appearing outside preview content.
- Fixed settings style scoping and state restoration after view changes.
- Removed haptic feedback after saving settings while preserving step feedback on the page scrubber.
