## 中文

### 新增
- 设置中新增发布记录，可查看历次更新说明，并支持键盘切换版本。
- 发现新版本时可以跳过当前版本；后续发现更高版本时仍会提醒。
- 托盘菜单新增“设置”，并展示常用操作的快捷键。

### 优化
- 更新检查、发布记录、加载和失败反馈统一在固定区域中呈现，状态更清晰。

### 修复
- 修复 macOS 全屏使用其他应用时，主面板无法在当前空间呼出的问题。
- 修复发布记录列表的焦点、键盘翻页与滚动边界。

## English

### Added
- Added release history in Settings with keyboard version navigation.
- You can now skip a detected version; newer versions will still be offered.
- Added Settings and shortcut hints to the tray menu.

### Improved
- Update checks, release history, loading, and error feedback now share one stable area.

### Fixed
- Fixed the panel appearing outside the active Space when another macOS app is full screen.
- Fixed focus, keyboard paging, and scroll boundaries in release history.
