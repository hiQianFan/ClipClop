## 中文

### 新增
- 软件更新现在支持分别下载与安装，并可取消下载、失败重试或稍后继续安装。
- 更新安装包改由 Cloudflare R2 分发，提升跨地区下载的稳定性。

### 优化
- 菜单、设置分类、文件导航和确认操作统一采用无障碍交互组件，键盘导航与焦点反馈更加一致。
- 快速入门的权限说明、操作按钮和语言菜单更加清晰。
- 软件更新页的加载占位、发布记录和进度状态更加稳定、易读。

### 修复
- 修复新旧版本配置字段不一致时可能无法启动的问题；旧版本会忽略未知字段，并在重新升级后继续继承配置。
- 修复设置分类、菜单与文件导航迁移后出现的样式和焦点回归。

## English

### Added
- Updates can now be downloaded and installed separately, with cancellation, retry, and deferred installation support.
- Update packages are now distributed through Cloudflare R2 for more reliable downloads across regions.

### Improved
- Menus, Settings tabs, file navigation, and confirmations now share accessible interaction primitives with more consistent keyboard and focus behavior.
- Permission guidance, action buttons, and the language menu in Quick Start are clearer.
- Loading placeholders, release history, and progress states on the Software Update page are more stable and readable.

### Fixed
- Fixed startup failures when settings contain fields written by a newer version; older versions now ignore unknown fields and preserve them for later upgrades.
- Fixed styling and focus regressions introduced while migrating Settings tabs, menus, and file navigation.
