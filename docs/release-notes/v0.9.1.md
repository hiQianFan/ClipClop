## 中文

### 改进
- 设置修改后立即保存，不再需要手动点击保存。
- 已就绪的辅助功能权限打开系统设置后继续保持就绪状态。
- 仅在新增辅助功能授权后提示重启，打开完全磁盘访问不再触发重启状态。

## English

### Improved
- Settings now save immediately without requiring a separate save action.
- Ready accessibility permissions remain ready after opening System Settings.
- Restart is requested only after granting accessibility access; opening Full Disk Access no longer triggers it.
