# 故障排查

## pnpm 或 Node.js 版本不匹配

运行 `nvm use`，再用 Corepack 启用项目锁定的 pnpm。CI 和本地都应使用 `pnpm install --frozen-lockfile`。

## macOS 无法编译或打包

确认已安装 Xcode Command Line Tools，并检查 `xcode-select -p`。Beta Xcode 可能导致 DMG Finder 布局脚本失败；[构建与分发](distribution.md) 中的 `hdiutil` 回退只适合本地测试，不代表签名和公证完成。

## 全局快捷键无响应

默认组合是 `⌃⌘C`（macOS）或 `Ctrl+Alt+C`（Windows）。如果没有响应，从托盘重新打开 ClipClop，在“设置 → 快捷键”中录制其他组合并保存；系统保留或已被其他应用占用的组合不会替换当前快捷键。

## 没有捕获某个应用的内容

检查该来源是否在忽略列表中。某些应用写入的剪贴板格式可能不受支持；来源名称也只是尽力归因。请用虚构内容复现，并在 issue 中提供平台、应用版本、内容类型和日志中的非敏感错误，不要粘贴真实内容。

## 文件预览失效

ClipClop 保存的是文件路径引用而不是源文件副本。源文件被移动、重命名、删除或权限变化后，打开/预览可能失败，但历史记录仍可存在。

## 如何重置本地数据

先从托盘完全退出应用，再删除操作系统为 `com.clipclop.desktop` 分配的应用数据目录。此操作不可恢复；路径会随平台和打包方式变化，因此正式发布前应补充各平台经过安装包验证的精确路径。
