# ClipClop 隐私说明

ClipClop 是离线优先的本地剪贴板历史工具。

- 剪贴板内容、来源应用、文件路径和设置只保存在当前设备。
- 应用没有账号、云同步、遥测、广告或内容分析服务。
- 复制的 URL 不会触发 favicon、SEO、Open Graph 或其他网络请求。
- ClipClop 默认保存平台允许读取的全部受支持格式，不推测或自动过滤所谓敏感内容。
- 用户可以暂停记录、忽略指定来源应用、删除单条、清空历史或调整保留期限。
- 文件记录保存路径引用；生成缩略图时可能读取源文件，但不会复制、移动或上传源文件。
- 本地数据库受当前系统用户权限和 FileVault/BitLocker 等系统磁盘保护；v1 不提供应用层数据库加密。

日志不得包含剪贴板正文、HTML/RTF payload、完整 URL 或文件路径。
