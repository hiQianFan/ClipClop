# ClipClop 隐私说明

ClipClop 是离线优先的本地剪贴板历史工具。

- 剪贴板内容、来源应用、文件路径和设置只保存在当前设备。
- 应用没有账号、云同步、遥测、广告或内容分析服务。
- 复制的 URL 不会触发 favicon、SEO、Open Graph 或其他网络请求。
- 启用自动检查更新时，应用最多每 24 小时向 GitHub Releases 请求一次公开的 `latest.json`；请求只用于比较版本和取得更新包，不包含剪贴板内容、历史、文件路径或来源应用信息。用户可在设置中关闭自动检查，手动检查仍只在明确操作时联网。
- ClipClop 默认保存平台允许读取的全部受支持格式，不推测或自动过滤所谓敏感内容。
- 用户可以忽略指定来源应用、删除单条、清空历史、调整保留期限或退出应用。当前版本不提供暂停记录功能。
- 文件记录保存路径引用；生成缩略图时可能读取源文件，但不会复制、移动或上传源文件。
- 本地数据库受当前系统用户权限和 FileVault/BitLocker 等系统磁盘保护；v1 不提供应用层数据库加密。

日志不得包含剪贴板正文、完整 URL 或文件路径。

## 数据位置与删除

历史与设置保存在操作系统分配给 `com.clipclop.desktop` 的应用数据目录中。删除单条或清空历史只删除 ClipClop 管理的数据，不会删除引用的源文件。卸载程序是否清理应用数据取决于操作系统和安装方式；需要彻底移除时，应在退出应用后删除对应应用数据目录。

## 当前限制

- 本地数据库未做应用层加密，安全性依赖当前系统账户权限和 FileVault/BitLocker 等磁盘保护。
- 来源应用属于尽力归因，可能为空或不准确。
- 项目尚未完成独立隐私审计；若未来加入联网能力、遥测或云同步，本说明必须在发布前更新。
