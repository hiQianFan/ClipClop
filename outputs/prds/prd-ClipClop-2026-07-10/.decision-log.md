# Clip-Clop PRD Decision Log

## Decisions

- 2026-07-10: Create PRD for Clip-Clop.
- 2026-07-10: Product baseline is a lightweight, modern, ready-out-of-the-box macOS + Windows clipboard history tool.
- 2026-07-10: v1 should not become AI clipboard, knowledge base, note-taking app, second brain, MCP tool, or agent product.
- 2026-07-10: Technical baseline is Tauri for desktop shell/UI, Rust for local core logic, and thin platform adapters for macOS/Windows system integration.
- 2026-07-10: PRD target is public launch MVP, not solo-only prototype.
- 2026-07-10: v1 is a free tool.
- 2026-07-10: MVP should include common clipboard content types, not text only.
- 2026-07-10: Product interaction should be similar in shape to Raycast Clipboard History: searchable list, type filter, preview/details pane, source metadata, keyboard-first confirmation.
- 2026-07-10: Confirming a selected item should update the system clipboard and attempt direct paste into the active app.
- 2026-07-10: "Direct paste" means user-confirmed paste from the Clip-Clop window via Enter or double-click, not unattended automatic paste.
- 2026-07-10: Encryption-at-rest is not a v1 blocker; MVP privacy relies on local-only storage, no telemetry, ignored apps/types, retention controls, and clear-history controls.
- 2026-07-10: Recommended UI stack for MVP is Svelte + TypeScript + Vite inside Tauri.
- 2026-07-10: macOS should have first-run permission onboarding for Accessibility/direct paste; Windows should not have an equivalent permission gate, but direct paste can be limited by UIPI for elevated apps.
- 2026-07-10: macOS clipboard read/write should not be framed as a user-granted permission; Accessibility is the MVP permission gate for direct paste. Avoid low-level keyboard event taps to avoid Input Monitoring.
- 2026-07-10: Public Raycast sources confirm React/Node/TypeScript for extensions, not necessarily the proprietary core app. Clip-Clop should borrow Raycast's interaction model, not infer its internal app stack.
- 2026-07-10: Visual direction should move toward liquid glass, but layout should be derived from clipboard-reuse flow rather than copying Raycast's exact two-pane structure.
- 2026-07-10: Preferred layout exploration starts with timeline stack plus expandable inspector; source-first and canvas-preview variants remain alternatives.
- 2026-07-11: Primary history list should be continuous recent-first, not grouped by Today/Yesterday/This Week. Copied time belongs in item metadata.
- 2026-07-11: Clipboard preview must faithfully render the copied payload only. No generated titles, explanations, summaries, rewrites, translations, or semantic enrichment in MVP.

## Deferred / Addendum Candidates

- Detailed architecture belongs in a technical architecture document after PRD scope is stable.
- Technical rationale for Tauri + Rust should be preserved outside the PRD body.
