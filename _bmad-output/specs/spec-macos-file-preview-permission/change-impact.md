# 功能变化与影响提案

## 用户体验变化

| 场景 | 当前行为 | 提案行为 |
| --- | --- | --- |
| 首次复制受保护目录中的文件 | 显式预览时可能出现系统权限弹窗 | 文件预览默认关闭，不读取原文件、不弹窗 |
| Settings | 没有文件访问授权入口 | 增加“文件预览”设置，提供“打开完整磁盘访问设置”和授权完成后的启用操作 |
| 快速入门 | 只引导辅助功能等现有能力 | 增加可跳过的文件预览权限说明与快捷入口 |
| 未授权的文件条目 | 预览尝试读取路径或调用 Quick Look | 只展示文件名或路径、来源应用、文件类型，并说明文件预览未开启 |
| 已授权且已启用 | 没有独立门控 | 保留现有显式文件预览体验 |
| 非文件剪贴内容 | 正常预览 | 不变 |
| Windows | 现有行为 | 不变 |

## 设置状态

新增一个持久化布尔设置“文件预览已启用”，默认值为关闭。该值只代表用户已完成授权并选择启用，不声称能够读取 macOS 的真实授权状态。

建议交互：

1. 用户点击“打开完整磁盘访问设置”。
2. ClipClop 打开 macOS 对应的隐私设置页面。
3. 用户手动为 ClipClop 开启权限并返回应用。
4. 用户点击“我已授权，开启文件预览”。
5. 此后只有显式预览操作读取原文件。

如果用户跳过、取消或不确认第 4 步，开关保持关闭，ClipClop 不访问原文件。

## 受影响模块

- Settings：增加 macOS 专属设置项、说明、系统设置跳转和持久化开关。
- 快速入门：增加可跳过的文件预览授权入口，并复用相同设置状态。
- 历史详情：关闭状态下停止文件资源和元数据请求，只渲染数据库已有信息。
- 原生预览命令：在共享入口再次校验设置，避免前端遗漏入口后仍读取文件。
- 设置存储与迁移：旧用户升级后默认关闭文件预览，优先保证不弹窗。
- 中英文文案与隐私说明：明确该功能、访问范围、可选性及降级行为。
- 自动化检查：覆盖默认关闭、拒绝授权、启用预览和非文件类型不受影响。

## 风险与取舍

- macOS 没有适合本场景的官方 API 让应用静默判断“完整磁盘访问”是否已开启，因此必须依赖用户确认；若用户未实际授权却手动开启，系统仍可能拒绝或提示访问。
- 完整磁盘访问的范围大于文件预览实际所需权限。提案将其设计为可选能力，并确保拒绝后核心剪贴功能完整可用。
- 老用户升级后文件预览会默认关闭，这是为彻底消除意外弹窗做出的兼容性取舍。

## 最终效果

- 默认体验无文件权限弹窗。
- 不授权的用户仍能保存并查看文件来源、名称和路径。
- 需要预览的用户可从 Settings 或快速入门直达一次性系统授权流程，并主动开启能力。
- 文件预览权限不会影响自动粘贴、文本和图片预览或 Windows 功能。

## 验收清单

- [x] 全新安装且未授权时，文件条目的浏览、选择和预览操作均不进入原文件操作。
- [x] 未启用时不执行原文件存在性检查、大小读取、图片解码或 Quick Look。
- [x] Settings 与快速入门均能打开 macOS 完整磁盘访问设置。
- [x] 快速入门可跳过权限步骤并完成。
- [x] 完成授权并启用后，文件继续进入原有 Quick Look 路径。
- [x] 撤销应用内开关后立即停止新的原文件读取，并等待已持锁读取结束。
- [x] 非文件类型与 Windows 行为没有回归。
